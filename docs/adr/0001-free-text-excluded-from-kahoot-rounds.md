# Free text is excluded from kahoot rounds

Kahoot rounds accept only `multiple_choice`, `sort` and `match` questions. `free_text` is left out even though it grades itself on submit, the same as those three. A kahoot round is a race in which faster answers score more, and a typed answer adds typing speed and spelling to that race, so the kahoot-allowed list is its own explicit list rather than being derived from the auto-graded types. The quiz editor only offers kahoot-allowed types in a kahoot round, and won't let kahoot mode be switched on while a round holds a disallowed question.
