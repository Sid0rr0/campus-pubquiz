# The quickfire mode lives on the quiz, not on its rounds or sessions

A quiz is either a pub quiz or a quickfire quiz, chosen when it is created and never changed; quickfire used to be a per-round flag (`kahootMode`) that could sit beside pub-quiz rounds in one quiz. Mixing them put 1000-point speed scores on the same leaderboard as 1-point pub answers, and every pub-quiz feature (jokers, power-ups, breaks, live edits, prior standings, feedback, leagues) needed its own exception for the odd round. A per-session mode was rejected because the allowed question types (ADR 0001) belong to the content and must be checkable in the editor, not only at session start; running quickfire as a separate game inside the night was rejected because two sessions back to back already do that without a new concept. The game engine still reads a per-round flag in memory, filled from the quiz's mode when a session is set up, so the block, reveal and timer logic did not change; expect that flag to be the same on every round of a session. The mode is fixed after creation because switching a quiz would mean re-validating its types, re-pointing its questions and reinterpreting the history of its ended sessions (league counts, team placings).
